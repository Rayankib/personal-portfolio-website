# Personal Portfolio

My static portfolio introduces my work in frontend development, UX/UI, interactive experiences and media. I share it alongside my CV when applying for ICT internships.

## Technologies

- HTML
- CSS
- JavaScript

## Local use

Open `index.html` in a browser. The site has no build step or package dependencies.

## Live site

https://rayankib.github.io/personal-portfolio-website/

## Project structure

- `index.html`: homepage and Selected Work
- `cz.html`, `ov09.html`: project case pages
- `css/style.css`, `js/main.js`: shared styling and interactions
- `assets/`: profile and optimized project images
- `docs/design-decisions.md`: iteration decisions, implementation notes and validation

The site uses relative local paths and is compatible with GitHub Pages.
